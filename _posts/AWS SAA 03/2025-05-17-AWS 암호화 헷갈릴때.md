#### **AWS Key Management Service (KMS)**

- **용도**: 암호화 키를 생성, 관리, 저장하는 **완전 관리형 서비스**.

------

#### **EBS 암호화**

- **용도**: EBS 볼륨에 저장된 데이터를 **미사용 시 암호화**.
- **특징**:
  - **기본 암호화 활성화**: AWS 계정 전체에서 EBS 볼륨 생성 시 자동 암호화 설정 가능.
  - **KMS 통합**: EBS 암호화 시 **KMS 키 (CMK 또는 AWS 관리형 키)** 사용 필수.

------

#### **S3 암호화**

- **종류**:
  - **SSE-S3**: S3가 관리하는 키로 암호화 (간편하지만 제어권 없음).
  - **SSE-KMS**: KMS 키로 암호화 (감사, 키 순환, 권한 제어 가능).
  - **SSE-C**: 사용자가 직접 키 제공 (복잡성 ↑).
  - **클라이언트 측 암호화**: 데이터 업로드 전에 암호화 (가장 안전하나 구현 복잡).

------

## **시험 문제 유형별 접근법**

#### **(1) "키 관리 권한"이 필요한 경우 → KMS 고객 관리형 키 (CMK)**

#### **(2) "최소한의 관리 오버헤드" 요구 시 → AWS 관리형 키**

#### **(3) "EBS 볼륨 암호화" 강제 → 기본 암호화 설정 + KMS 통합**

#### **(4) "비준수 리소스 자동 수정" → AWS Config + Systems Manager**

------

### **암호화 문제 풀이 핵심 체크리스트**

1. **키 제어권 필요?**
   - Yes → **KMS 고객 관리형 키 (CMK)**.
   - No → **AWS 관리형 키** 또는 **SSE-S3**.
2. **암호화 강제 필요?**
   - IAM 정책으로 **암호화된 리소스만 생성 허용** (예: `Condition: kms:EncryptionContext`).
3. **기존 리소스 암호화?**
   - **AWS Config**로 비준수 리소스 감지 → **Systems Manager**로 수정.
4. **암호화 유형**
   - **EBS 볼륨**: KMS 키 필수.
   - **S3 객체**: SSE-KMS, SSE-S3, SSE-C 중 선택.
   - **RDS 데이터베이스**: KMS 키로 암호화 가능.
5. **키 순환 주기**
   - **KMS 고객 관리형 키**: 연간 자동 순환 가능.
   - **AWS 관리형 키**: AWS가 관리 (사용자 제어 불가).

**AWS Secrets Manager**는 **자동화된 자격 증명 순환**을 지원하는 완전 관리형 서비스입니다.
