### **Redis와 Memcached**는 모두 인메모리 데이터 저장소(in-memory data store)로, 웹 애플리케이션의 성능을 향상시키기 위해 데이터를 빠르게 캐싱하는 데 사용됩니다. 



## Memcached:

- **단순하고 빠른 캐싱:**

  단순한 키-값 구조를 사용하며, 문자열 기반 데이터를 캐싱하는 데 최적화되어 있습니다.

- **고성능:**

  빠른 응답 시간(1ms 미만)을 제공하며, 트래픽이 몰려도 안정적인 응답 속도를 유지합니다.

- **단일 스레드:**

  싱글 스레드 구조로, 병렬 처리보다는 캐싱에 집중된 형태로 설계되어 있습니다.

- **복제 지원 안됨:**

  복제 기능을 지원하지 않으므로, 단일 서버에 장애가 발생하면 데이터 손실이 발생할 수 있습니다.

------

## Redis:

- **다양한 자료구조:**

  문자열, 해시, 리스트, 집합 등 다양한 자료구조를 지원하여 다양한 용도로 활용할 수 있습니다.

- **스냅샷, 복제, 트랜잭션, Pub/Sub:**

  다양한 기능을 지원하여 복잡한 애플리케이션에 적합합니다.

- **싱글 스레드:**

  Memcached와 달리 싱글 스레드 구조로, 성능을 더 높이기 위해 여러 Redis 인스턴스를 사용하는 것이 좋습니다.

- **복제 지원:**

  복제 기능을 지원하여 데이터 손실을 방지할 수 있습니다
