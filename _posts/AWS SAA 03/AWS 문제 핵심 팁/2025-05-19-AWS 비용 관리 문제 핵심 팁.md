##  **주요 서비스별 특징**

| **서비스**                    | **용도**               | **주요 기능**                                                |
| :---------------------------- | :--------------------- | :----------------------------------------------------------- |
| **AWS Cost Explorer**         | 비용 시각화 및 분석    | - 과거/현재 비용 추세 분석 - 태그/서비스/리전별 필터링 - 12개월 예측 |
| **AWS Budgets**               | 예산 설정 및 초과 알림 | - 비용/사용량/RI/Savings Plan 예산 관리 - Slack/이메일 알림  |
| **Cost & Usage Report (CUR)** | 상세 청구 보고서 생성  | - 모든 비용 데이터를 CSV/Parquet로 내보내기 - Redshift/QuickSight와 통합 |
| **Cost Allocation Tags**      | 리소스별 비용 분류     | - 태그 기반 비용 추적 (예: `Application=Web`)                |

 **AWS Billing and Cost Management**는 AWS 비용을 관리하고, 결제 및 청구서를 처리하며 예산을 설정하고 모니터링하는 전체적인 솔루션입니다. 반면, 

**AWS Cost Explorer**는 Billing and Cost Management 콘솔 내에서 비용과 사용량을 시각화하고 분석하는 데 사용되는 도구

------

### Billing and Cost Management는 AWS 비용 관리를 위한 전체적인 플랫폼이고, Cost Explorer는 그 플랫폼 내에서 비용 분석을 위한 도구
