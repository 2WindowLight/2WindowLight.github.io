### CORS (Cross-Origin Resource Sharing)는 서버가 다른 출처로부터의 웹 페이지 요청을 허용하거나 거부할 수 있도록 하는 HTTP 헤더 기반의 메커니즘

------

**브라우저의 동일 출처 정책을 우회하여 교차 출처 접근을 허용함으로써 웹 사이트 간 통신을 가능하게 합니다.** 



**참고: 복제가 아닌 다른 도메인에서 웹 페이지의 리소스를 요청하는 데 사용됨**
