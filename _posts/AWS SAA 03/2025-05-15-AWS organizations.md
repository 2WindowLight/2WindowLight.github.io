### AWS Organizations는 AWS 계정을 중앙에서 관리하고 관리하는 서비스입니다. 

### 여러 AWS 계정을 하나의 조직으로 통합하여 계정을 생성, 관리, 제어할 수 있도록 해줍니다

------

### 주요 기능:

* **계정 관리**
* **통합 결제**
* **거버넌스**
* **정책 기반 관리**

------

### 추가 정보:

- **AWS Organizations는 추가 비용 없이 제공됩니다.**
- **정책을 통해 계정 간 권한을 제어할 수 있습니다.**
- **조직 단위(OU)를 사용하여 계정을 계층적으로 그룹화할 수 있습니다.**
- **조직을 삭제하기 전에 모든 계정을 제거해야 합니다.** 

------

## AWS Organizations는 복잡한 환경에서 AWS 리소스를 효율적으로 관리하고 안전하게 유지하는 데 필요한 기능을 제공합니다
