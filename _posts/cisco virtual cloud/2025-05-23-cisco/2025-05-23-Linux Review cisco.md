### **Linux 핵심 명령어 요약** (Lab - Linux Review)

#### **Part 2: 기본 명령어 & 네비게이션**
| 명령어          | 기능 설명                                        |
| --------------- | ------------------------------------------------ |
| `ls`            | 현재 디렉토리 내용 표시                          |
| `ls -l`         | 파일 상세 정보 (권한, 소유자 등)                 |
| `ls -r`         | 역순(alphabetical)으로 출력                      |
| `pwd`           | 현재 작업 디렉토리 경로 출력                     |
| `cd [경로]`     | 디렉토리 이동 (예: `cd /home/devasc`)            |
| `cd ..`         | 상위 디렉토리로 이동                             |
| `sudo [명령어]` | 관리자 권한으로 실행 (예: `sudo apt-get update`) |

---

#### **Part 3: 파일 관리**
| 명령어                    | 기능 설명                                         |
| ------------------------- | ------------------------------------------------- |
| `chmod +x [파일]`         | 파일 실행 권한 추가 (예: `chmod +x script.sh`)    |
| `chown [사용자] [파일]`   | 파일 소유자 변경 (예: `sudo chown root file.txt`) |
| `mv [파일] [경로]`        | 파일 이동/이름 변경 (예: `mv old.txt new.txt`)    |
| `cp [파일] [복사본]`      | 파일 복사 (예: `cp file.txt backup.txt`)          |
| `rm [파일]`               | 파일 삭제                                         |
| `echo "텍스트" > [파일]`  | 파일 생성 및 텍스트 쓰기 (덮어쓰기)               |
| `echo "텍스트" >> [파일]` | 파일에 텍스트 추가 (append)                       |
| `cat [파일]`              | 파일 내용 출력                                    |

---

#### **Part 4: 정규 표현식 (grep)**
| 명령어                  | 기능 설명                          |
| ----------------------- | ---------------------------------- |
| `grep "패턴" [파일]`    | 파일에서 패턴 검색 (대소문자 구분) |
| `grep -i "패턴" [파일]` | 대소문자 무시 검색                 |
| `grep '^시작' [파일]`   | 줄 시작에 "시작"이 있는 경우       |
| `grep '끝$' [파일]`     | 줄 끝에 "끝"이 있는 경우           |
| `grep '[0-9]' [파일]`   | 숫자가 포함된 줄 검색              |

---

#### **Part 5: 시스템 관리**
| 명령어                          | 기능 설명                               |
| ------------------------------- | --------------------------------------- |
| `shutdown now`                  | 즉시 시스템 종료                        |
| `shutdown +5 "메시지"`          | 5분 후 종료 (+ 메시지 표시)             |
| `ip address`                    | 네트워크 인터페이스 정보 확인           |
| `ping -c 4 [IP]`                | 특정 IP로 4회 ping 테스트               |
| `ps`                            | 현재 터미널에서 실행 중인 프로세스 표시 |
| `ps -ef`                        | 모든 프로세스 상세 정보 표시            |
| `sudo apt-get install [패키지]` | 패키지 설치                             |
| `sudo apt-get purge [패키지]`   | 패키지 완전 삭제                        |
| `passwd`                        | 현재 사용자 비밀번호 변경               |

---

### **Key Tips**:
- **`man [명령어]`** 또는 **`[명령어] --help`**로 도움말 확인 (예: `man ls`).
- **탭(Tab) 자동 완성**으로 빠른 경로 입력 가능.
- **`>`**는 파일 덮어쓰기, **`>>`**는 파일에 추가.
