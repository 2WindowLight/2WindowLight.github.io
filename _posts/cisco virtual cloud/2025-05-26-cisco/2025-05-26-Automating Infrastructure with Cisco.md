## 

### **Cisco 네트워크 자동화 솔루션 요약**  

#### **1. Walk (읽기 전용 자동화)**  
- **목적**: 네트워크 구성 정보 수집 및 변경 사항 확인 ("무엇이 변경되었는가?")  
- **장점**:  
  - 읽기 전용(GET 요청)으로 안전하게 데이터 수집  
  - 구성 감사 및 준수 상태 복원 가능  
- **적용 사례**:  
  - 네트워크 모니터링, 설정 백업, 변경 로그 분석  

------

#### **2. Run (정책 기반 자동화)**  
- **목적**: 사용자 셀프 서비스 및 반복 작업 자동화  
- **주요 기능**:  
  - 네트워크 프로비저닝 (Day 0/Day 1/Day N)  
  - 워크플로우 자동화 (예: 장비 온보딩, 일상 구성 관리)  
- **적용 사례**:  
  - 정책 적용, 대량 설정 배포, 멀티 도메인 관리  

------

#### **3. Fly (CI/CD 통합 고급 자동화)**  
- **목적**: 지속적 통합/배포(CI/CD)를 통한 애플리케이션 및 네트워크 구성 관리  
- **주요 기능**:  
  - 텔레메트리 데이터 분석을 통한 사전 예방적 운영  
  - 복잡한 자동화 워크플로우 구현 (예: 애플리케이션 배포, 설정 템플릿 적용)  
- **적용 사례**:  
  - DevOps 환경, 클라우드 네트워킹, 대규모 인프라 최적화  

#### **DevNet Automation Exchange**  
- 시스코가 제공하는 자동화 도구 및 사용 사례 플랫폼  
- Walk → Run → Fly 단계별 솔루션 탐색 및 커뮤니티 기반 예제 공유 가능  

> **핵심**: 단계별 접근으로 네트워크 운영 효율성과 안정성을 극대화할 수 있습니다.
