### Cisco 라우팅 프로토콜 전체 정리 (알파벳 코드 포함)

#### 1. **IGP (내부 게이트웨이 프로토콜)**
| 프로토콜           | 알파벳 코드 | AD 값 | 특징                                                 |
| ------------------ | ----------- | ----- | ---------------------------------------------------- |
| **EIGRP**          | D           | 90    | 시스코 전용, 복합 메트릭(대역폭/지연), DUAL 알고리즘 |
| **OSPF**           | O           | 110   | 링크 상태 프로토콜, LSA 활용, Area 분할 설계         |
| **RIP**            | R           | 120   | 거리 벡터, 홉 카운트 제한(15), v1/v2/ng 버전 존재    |
| **IS-IS**          | i           | 115   | OSI 기반, SPF 알고리즘, ISP 네트워크에서 주로 사용   |
| **EIGRP External** | D EX        | 170   | 외부 EIGRP 경로 (재분배된 경로)                      |

#### 2. **EGP (외부 게이트웨이 프로토콜)**
| 프로토콜 | 알파벳 코드 | AD 값              | 특징                                          |
| -------- | ----------- | ------------------ | --------------------------------------------- |
| **BGP**  | B           | 20(eBGP)/200(iBGP) | 경로 벡터, AS_PATH 속성, 인터넷 백본에서 사용 |

#### 3. **기타 라우팅 유형**
| 유형          | 알파벳 코드 | AD 값 | 설명                                       |
| ------------- | ----------- | ----- | ------------------------------------------ |
| **Connected** | C           | 0     | 직접 연결된 네트워크                       |
| **Static**    | S           | 1     | 관리자가 수동 구성                         |
| **Default**   | S*          | 1     | 0.0.0.0/0으로 표기되는 기본 라우트         |
| **Local**     | L           | 0     | 라우터 자체 인터페이스 주소 (예: Loopback) |

---

### 📌 특수 코드 추가 설명
- **`>`**: 최적 경로로 선택됨 (라우팅 테이블에서 경로 앞에 표시)
- **`[AD/메트릭]`**: 예) `[120/2]` → AD=120, 메트릭=2
- **`via`**: 넥스트홉 주소 또는 출구 인터페이스

---

### 🔍 **실제 라우팅 테이블 예시**
```bash
C      192.168.1.0/24 is directly connected, FastEthernet0/0
D      10.1.1.0/24 [90/30720] via 192.168.1.1
O      172.16.1.0/24 [110/2] via 10.1.1.1
S*     0.0.0.0/0 [1/0] via 203.0.113.1
B      198.51.100.0/24 [20/0] via 203.0.113.5
```

### 💡 **참고 사항**
1. **AD 값 우선순위**: 숫자가 낮을수록 우선순위 높음 (Connected(0) > Static(1) > eBGP(20) > ...)
2. **메트릭 비교**: 동일 AD 시 메트릭이 낮은 경로 선택
3. **시스코 전용 프로토콜**: EIGRP만 D 코드 사용 (타 벤더 장비 호환 불가)
